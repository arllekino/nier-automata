# Теория автоматов и формальных языков

Набор учебных программ на C++20 по автоматам, регулярным выражениям и грамматикам. Репозиторий объединяет несколько самостоятельных заданий.

## Содержание

- `Lexer/` — лексический анализатор; примеры запуска в каталоге принимают на вход файлы с расширением `.Swift`.
- `Grammar/` — обработка входного файла и запись результата в выходной файл; README модуля содержит пример вызова для DOT-файла.
- `NKAtoDKA/` — преобразование недетерминированного конечного автомата в детерминированный.
- `Minimization/` — минимизация автомата.
- `MealyToMooreAndMooreToMealy/` — преобразования автоматов Мили и Мура.
- `RegularExpression/` — задания с регулярными выражениями.

## Сборка

В корне находится CMake-проект. Нужны CMake 3.30 или новее и компилятор с поддержкой C++20.

```bash
cmake -S . -B build
cmake --build build
```

Для запуска конкретного задания проверь его каталог и соответствующий CMake target: форматы входных данных и параметры запуска могут различаться.

## Назначение

Репозиторий демонстрирует классические преобразования и инструменты из теории формальных языков и автоматов; это набор отдельных учебных программ, а не единое приложение.
